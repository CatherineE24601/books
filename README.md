## 致恨

研一不忙的时候，我坐地铁去二校区图书馆，或者去工程坐着。初中寒假学校偷偷给我们上课，不想被教委抓，就让我们去工程学校租的教室，在主楼的楼顶上。主楼很老很昏暗，走在里面有医院的感觉，到处都是关着的实验室，有模糊的玻璃门和消毒水的味道。我经常六点爬起来，冒着大雪从门口走到主楼，背着我的那些卷子。我没有什么朋友，那时没有，读研也没有，你们让我以为你们是朋友，最后都是来偷我东西的，我恶毒的同门。

想到我的过去我无法与别人交流回忆，我只能去那里坐着。我读研有一次去那里发呆，困在我的过去，思考我的未来，迷惑我读研的当下。原来我是这么讨厌你们啊，想着你们的自私和伤害，我惧怕未来，害怕以后的人生也是如此，没有关怀，没有善意，像你们一样勾心斗角，只有欺骗和虚伪。

我恨我的论文写别人的名字，我恨帮博士写国自然，我恨你所谓的信任，我不是你们的自己人，我只是一个工具人，你们只想让我当牛做马。我恨我的垃圾同门师兄师姐，你们为什么还好好活着，你们为什么还不去死啊。

研三的我在写致谢时突然意识到，原来我是如此憎恶你们，我甚至无法写出我要谢的具体的话，我的致谢像个AI，AI都比我能说出自己被课题组关照的表现，我不知道，我不知道我要谢什么，我真的好恨你们，你们每个人都在骗我，从开学就在骗我。不，不会这样，余生我遇到的每个人都比你们好。

我不想跟你们这些SB再见了，你们快滚吧。哎呀，居然问我我不见你们，这样做是不是太伤你们的心了。SUNNY MUD TOE!!
